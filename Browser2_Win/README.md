Browser2 is a web browser application designed for Windows.

It's a secondary browser that adds the ability to use tabs and manage multiple web pages simultaneously.

It provides users with a fast and secure browsing experience, supporting modern web standards and technologies. Browser2 includes features such as tabbed browsing, bookmarks, history management, and customizable settings to enhance user convenience. It is built to be lightweight and efficient, ensuring optimal performance on Windows operating systems.

For developers: 

- Browser2 is an example of a browser built using tabs and multiple tabs each with their own webview2 and browserbar.
- Browser2 doesn't have a webview environment explicit or support extensions
- Browser3 will cover the webview environment and extension support, which will be a more advanced version of Browser2.
