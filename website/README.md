# Website for Browser_WIN

This folder contains a simple static website for the Browser_WIN project. It is intended to be deployed from the website/dev branch into GitHub Pages or served as a static site.

Files added:
- index.html — homepage and project overview
- assets/styles.css — styling for the site
- .nojekyll — prevents Jekyll processing (optional but recommended for static assets)

Deployment notes:
- If you want to use GitHub Pages for this site, you can configure Pages to use the website/dev branch and serve from the repository root, or copy the contents into the repository's docs/ folder on the branch you use for Pages.
- The site is intentionally lightweight (no build step). If you prefer a Jekyll theme or a modern static site generator (Hugo/Eleventy), I can convert it.
